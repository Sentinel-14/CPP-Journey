# CPP-Journey 🚀

A comprehensive C++ learning repository documenting a structured journey through fundamental and advanced C++ programming concepts.

## 📚 Overview

This repository contains daily practice exercises and implementations covering various C++ topics, from basic programming constructs to advanced data structures and algorithms. Each day focuses on specific concepts with practical examples and exercises.

## 🔧 How to Compile and Run

Each C++ file can be compiled and run independently using a C++ compiler like g++:

```bash
# Compile a single file
g++ -o output_file source_file.cpp

# Run the compiled program
./output_file
```

Example:
```bash
cd Day21
g++ -o mergesort mergesort.cpp
./mergesort
```

For Windows:
```bash
g++ -o program.exe source_file.cpp
program.exe
```
