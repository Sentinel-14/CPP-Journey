A C++ learning repository containing various algorithm implementations, data structure examples, and practical programming exercises.

## Repository Structure

This repository is organized by days, with each folder containing C++ programs related to different topics:

- **day5-day21**: Various C++ programming exercises including:
  - Data structures (arrays, linked lists, etc.)
  - Algorithms (sorting, searching, recursion, etc.)
  - Problem-solving exercises

### Day 22: Login Form Validation

A comprehensive login form validation program demonstrating input validation techniques in C++.

**File**: `day22/LoginFormValidation.cpp`

**Features**:
- Username validation (5-20 characters, alphanumeric with underscores, must start with letter)
- Email validation (proper email format with @ and domain)
- Password validation (minimum 8 characters, must include uppercase, lowercase, digit, and special character)
- Password confirmation matching

**How to compile and run**:
```bash
cd day22
g++ -o LoginFormValidation LoginFormValidation.cpp -std=c++11
./LoginFormValidation
```
